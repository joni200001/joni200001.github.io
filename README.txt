# মা অনলাইন সলিউশন এন্ড গ্রাফিক্স ডিজাইন — ফ্রি ওয়েবসাইট

ফাইল:
- `index.html` — সম্পূর্ণ ওয়েবসাইট
- `business-banner.png` — আপনার দেওয়া ব্যানার/ছবি

## GitHub Pages-এ ফ্রি প্রকাশ
1. GitHub-এ একটি নতুন repository তৈরি করুন।
2. `index.html` এবং `business-banner.png` আপলোড করুন।
3. Repository-এর Settings → Pages-এ গিয়ে Branch হিসেবে `main` নির্বাচন করে Save করুন।
4. কিছু সময় পর GitHub একটি ফ্রি ওয়েবসাইট ঠিকানা দেবে।
